A simple project created to practice basic HTML structure and foundational markup. This repository contains introductory-level code focused on understanding elements, tags, and page layout.

- Clean and readable markup

- Easy to extend for future practice

This project was created as an early exercise in learning HTML. It serves as a starting point for understanding how webpages are structured and how elements work together.
